# HomeStock 🏠📦

> **"Buy only what you need. Never run out of what you need."**

HomeStock is a consumer mobile application and backend service built for individuals and families to manage household inventory, maintain shared shopping lists, record grocery purchases, track expiration dates, and get smart low-stock recommendations.

---

## 📸 Core Features & Consumer UX Highlights

1. **Multi-Home Household Switching & RBAC**:
   - Create and manage multiple households (e.g. *Main Apartment*, *Parents' Home*, *Beach House*).
   - Generate secure 8-character invite codes for family members.
   - Built-in role hierarchy: `OWNER`, `ADMIN`, `MEMBER`, and `VIEWER`.

2. **Automated Low-Stock Trigger & Shared Shopping List**:
   - When any product's quantity drops to or below its minimum threshold (`quantity <= minimumQuantity`), the backend **automatically generates** a replenishment item in the household's shared shopping list (`isAutoGenerated = true`).
   - Cross off items in real time while grocery shopping.

3. **Atomic Purchase Logging & Auto-Restock Engine**:
   - In a single transactional operation (`@Transactional`), record a grocery run with store name, total cost, and line items.
   - The backend automatically:
     - Increases the respective inventory quantities.
     - Logs an immutable `STOCK_IN` transaction in the audit history.
     - Automatically marks corresponding items on the shopping list as completed!

4. **Expiry Date Monitoring & Scheduled Alerts**:
   - Classifies food and medicine items dynamically into:
     - `EXPIRED` (past best-before date)
     - `EXPIRING_SOON` (within 3 days)
     - `SAFE`
   - Automated daily Spring `@Scheduled` background worker scans for expiring items and creates alerts.

5. **"What Do I Need?" Intelligent Restock Recommendation**:
   - Deterministic urgency engine categorizing household items before grocery trips:
     - 🚨 **URGENT**: Items currently at 0 stock.
     - ⚠️ **SOON**: Items currently below minimum threshold.
     - 💡 **OPTIONAL**: Frequently consumed staples that will run low soon.

6. **Household Spending Analytics & Monthly Trends**:
   - Visual category-wise spending breakdown, monthly expenditure trends, and most-purchased household goods.

## 🚀 Getting Started

### Prerequisites
- **Java**: JDK 21 LTS
- **Maven**: 3.9+
- **Docker & Docker Compose**: (For PostgreSQL)
- **Flutter**: Flutter SDK 3.41+ and Dart 3.11+

---

### Step 1: Start PostgreSQL Database

Start the dedicated PostgreSQL 16 container on port `5433`:
```bash
docker compose up -d
```
Verify container status:
```bash
docker ps --filter "name=homestock-postgres"
```

---

### Step 2: Start Spring Boot Backend

Navigate to the `backend/` directory and run:
```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk-21.0.10"
mvn spring-boot:run
```

- Backend API: `http://localhost:8080/api/v1`
- Interactive Swagger UI: `http://localhost:8080/swagger-ui.html`
- OpenAPI Specification: `http://localhost:8080/v3/api-docs`

To run the automated backend test suite:
```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk-21.0.10"
mvn clean test
```

---

### Step 3: Run Flutter Mobile App

Navigate to the `frontend/` directory:
```bash
cd frontend
flutter pub get
```

To run Flutter widget tests:
```bash
flutter test
```

To run static analysis:
```bash
flutter analyze
```

To run the app on an Android emulator or Web:
```bash
# Web Chrome
flutter run -d chrome

# Android Emulator (ensure emulator is booted)
flutter run -d android
```
